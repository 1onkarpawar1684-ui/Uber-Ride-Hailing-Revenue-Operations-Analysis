# 🚗 Uber Ride-Hailing Revenue & Operations Analysis 📊 Status

A Power BI-based **Uber Ride-Hailing Revenue & Operations Analysis** project developed to analyze booking performance, revenue, vehicle types, customer behavior, driver performance, and operational trends through an interactive business intelligence dashboard.

---

## 📖 Project Overview

This project analyzes Uber ride-hailing data to understand how the business performs across different **vehicle types, booking statuses, locations, time periods, and customer/driver ratings**.

The interactive Power BI dashboard converts raw ride transaction data into meaningful **KPIs, trends, comparisons, and business insights**.

The project focuses on using **Power BI, DAX, Power Query, data cleaning, data transformation, and data modeling** to solve a real-world business analytics problem.
